🚗 FWCAM Vehicle Position Marker

Visual Enhancement for Map Previews

✨ What's New?

Map previews in the trip edit dialog now display a red position marker showing the exact location of the vehicle. This makes it easy to identify where your trip started or ended at a glance!

🔧 Technical Details

  • ✓ Uses Web Mercator projection for accurate positioning
  • ✓ SVG overlay on OpenStreetMap tiles
  • ✓ No external dependencies or API calls
  • ✓ Works in all modern browsers
  • ✓ Consistent 8px outer radius + 3px center dot design
