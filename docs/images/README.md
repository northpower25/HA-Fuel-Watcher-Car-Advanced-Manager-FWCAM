# FWCAM Card Preview Image

This directory should contain screenshots of the FWCAM custom Lovelace card.

## Recommended Screenshots

1. **fwcam-card-preview.png** - Full card with all sections (referenced in README.md)
2. **fwcam-card-light.png** - Light mode screenshot
3. **fwcam-card-dark.png** - Dark mode screenshot
4. **fwcam-card-mobile.png** - Mobile view screenshot
5. **fwcam-card-sections.png** - Individual sections breakdown

## How to Take Screenshots

1. Install the FWCAM integration in Home Assistant
2. Install the custom card following [REFUELING_LOG_GUIDE.md](../REFUELING_LOG_GUIDE.md)
3. Configure the card with sample data
4. Take screenshots using:
   - Browser screenshot tool (Ctrl+Shift+S in Firefox)
   - Home Assistant's built-in screenshot feature
   - Or external tools

## Image Specifications

- **Format**: PNG (for transparency support)
- **Width**: 800-1200px (for good quality without being too large)
- **Quality**: High quality, but compressed for web
- **Content**: Should show realistic data (not all zeros or N/A)
